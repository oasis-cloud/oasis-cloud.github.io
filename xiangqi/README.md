# 楚汉 · 象棋

浏览器里的工笔重彩中国象棋。棋子是程序化的古代军士，不是字面圆片。规则、搜索、材质、声音全部手写。

## 怎么玩

站点把 `docs/public/` 发到根路径，打开 **`/xiangqi/`**。首页「中国象棋」会跳转到此。本地在仓库根目录 `npm start`，然后访问同一路径。

## 架构

```
core/       棋盘常量、矿物色板、格点坐标
engine/     规则、Zobrist、评估、Alpha-beta、开局库、Worker
render/     工笔 Shader、描边、Sobel、程序纹理
units/      共享骨架、硬边几何、汉楚形制、动画、IK、三拍吃子
world/      木案棋盘、千里江山、弹簧镜头
ui/         绢色 HUD、棋谱、复盘、Web Audio、存档
game.js     对局编排
```

Three.js 只从 CDN 引入 `three@0.170.0`。不下载网格、贴图、字体、音频、棋库文件。

## 规则测试

```bash
node docs/public/xiangqi/engine/tests.js
```

覆盖飞将、蹩马腿、塞象眼、炮架、过河、困毙、将死、开局 perft。长将与六十回合在 `engine/repetition.js`，由对局层调用。

## 剪影模式

对局中点「剪影」，或 URL 加 `?silhouette=1`。用来核验兵种能不能只靠轮廓认出来。

## 质量自评（诚实）

- **规则引擎**：开局 perft 红 44 / 两层 1920，测试套件应全绿。困毙按负、长将、六十回合已接线。弱社难度是受限深度 + 有界噪声，并剔除大漏着；不是随机送车。
- **工笔管线**：4 档量化 ramp、墨线倒壳、Sobel 内轮廓、阴影绢纹都在。级联阴影改成单盏紧正交光，避免多 cascade 把色带洗灰。
- **角色**：14 种模板（七兵种 × 汉楚），共享骨架蒙皮。汉是朱砂雉尾，楚是墨甲高冠戈，不是换色。马/象的蹄步绑定大约六成——腿贴马腹有 IK 约束，但马身本身不是全骨骼四蹄 IK，侧向走时仍可能读出一点滑。
- **吃子**：三拍时间是 0.73 / 0.17 / 0.91，炮走抛物线石弹，颜料是硬边薄片不是雾。接触锁定（手不离兵、脚不穿地）靠挂接 + IK，不是影像级动作捕捉。
- **捕获工具链**：没有 Playwright 无头管线（避免给博客仓库加一套浏览器依赖）。用剪影按钮和浏览器截帧代替。动画重量只能在实机运动里看。
- **HUD**：竖排棋谱、评估墨条、印章按钮是 DOM，做成绢色而不是默认灰按钮；被吃子会停到棋盘两侧倒下，同时也在边缘列出文字。
