古代汉语

通论语法总表

作者：oasis

术语、定义和例句按下面的顺序排列：词类、词类活用、代词特殊结构、基本句型、特殊语序、省略句、兼词、特殊句式（连动、递系、“之”取独）、词汇构词。

一、词类系统

（一）实词

1. 名词

表示人、事物、地点。作主语、宾语、定语。

齐侯纳之，以为诸公子之傅（《鲁施氏有二子》）

侯、公子、傅，名词。

2. 动词

动作、变化、判断；作谓语，分及物 / 不及物。

孟氏之一子之秦，以术干秦王

干：动词，干谒求仕；之：动词，前往（王力重点：动词“之”≠助词）。

3. 形容词

性质、状态；作定语、谓语、状语。

孟氏父子舍然无愠容

愠：形容词，恼怒。

4. 数词

基数、序数、分数、约数、虚数。

  • 基数：鲁施氏有二子（二子，两个儿子）
  • 分数：藉第令毋斩，而戍死者固十六七（《史记·陈涉世家》，十分之六七）
  • 虚数：千千万臣而无数者也（《九方皋相马》，千万：虚数，极多）

5. 量词

名量词、动量词。上古汉语量词不发达。

  • 名量：一箪食，一瓢饮（《论语》）
  • 动量：三战三北（三次作战，三次败逃）

6. 代词

王力单列重点。

  • 人称代词：吾、我、余、予（第一人称）；汝、尔、若（第二人称）；其、之（第三人称）。例：子之年长矣（子：第二人称代词，您，《九方皋相马》）
  • 指示代词：此、是、斯（近指，这）；彼、夫（远指，那）。例：是灭亡之道（是：指示代词，这，《鲁施氏有二子》）
  • 疑问代词：谁、孰、何、奚、安、焉。例：又何马之能知也（何：疑问代词，什么，《九方皋相马》）

者、所是特殊指示代词，构成名词性短语。

  1. 者字结构：动词 / 形容词 + 者 → “……的人 / 物”（动作发出者，施事）。公式：V + 者。
    • 好学者以术干齐侯（好学者：喜爱学问的人）
    • 子所使求马者（求马者：寻找马匹的人）
  2. 所字结构：所 + 动词 → “被……的事物”（动作对象，受事）。公式：所 + V。
    • 所务兵食而已（所务：所致力的事务，《鲁施氏有二子》）
    • 若皋之所观，天机也（所观：所观察到的东西，《九方皋相马》）

（二）虚词

1. 副词

程度、范围、时间、否定、情态。

  • 否定副词：不、弗、毋、勿。例：色物牝牡尚弗能知（弗：不）
  • 范围副词：皆、尽、悉。例：臣之子皆下才也（皆：都）
  • 时间副词：既、已。例：既反，孟氏之父子叩胸而让施氏（既：……之后）
  • 情态副词：固、乃。例：是乃其所以千万臣而无数者也（乃：就是）

2. 介词

于（乎）、以、为、与。引出对象、工具、处所、原因。介宾常后置。

  • 于：窘于贫（于，引施事，被贫穷困迫）
  • 以：以术干齐侯（以，用，凭借）
  • 乎 = 于：贵乎马者也（乎，比）

3. 连词

而、以、则、且、虽、若、故。承接 / 转折 / 递进 / 假设。

  • 而（承接）：遂刖之，而还诸鲁（而后，表先后）
  • 而（转折）：子道与吾同，而功与吾异（但是）
  • 若（假设）：若用仁义治吾国，是灭亡之道（如果）

4. 语气词

句末：

  • 也：表判断、肯定。例：果天下之马也
  • 矣：已然、将然。例：已得之矣（已经找到了）
  • 乎：疑问。例：子姓有可以求马者乎？
  • 哉：感叹。例：焉往而不穷哉？

句首 / 句中：夫、盖、惟（维）。

夫战，勇气也（夫，句首发语词）

5. 词头、词尾

  • 形容词词尾 然、如、尔，译为“……的样子”。例：伯乐喟然太息（喟然：长叹的样子）
  • 词头：有，用于国名、族名前，有虞、有周

二、词类活用

定义：本是甲类词，在句中临时具备乙类词语法功能。

1. 名词用作一般动词

名词临时充当谓语，表动作。

遂宫而放之（宫，名词，宫刑；活用动词：施加宫刑）

2. 名词作状语

名词放在动词前修饰谓语。四类翻译：像……一样；在……；从……；按……。

蚕食诸侯（《战国策》，蚕：像蚕一样吞食）

3. 使动用法

主语使宾语产生动作或状态，客观致使。

  1. 动词使动：项伯杀人，臣活之（活之 = 使之活，使他活下来）
  2. 形容词使动：禄富其家，爵荣其亲（富其家 = 使其家富；荣其亲 = 使其亲荣耀，《鲁施氏有二子》）
  3. 名词使动：纵江东父兄怜而王我（王我：使我为王，《史记》）

4. 意动用法

主语主观认为宾语怎么样，主观认定，不改变客观事物。

  1. 形容词意动：吾妻之美我者，私我也（美我：以我为美，认为我美，《邹忌讽齐王纳谏》）
  2. 名词意动：侣鱼虾而友麋鹿（友麋鹿：把麋鹿当成朋友，《赤壁赋》）

辨析：使动是让宾语发生变化；意动是心里把宾语看成什么。

三、三大基本句型

判断句、叙述句、描写句（王力通论 7、8）。

1. 判断句

上古汉语没有系词“是”，“是”是指示代词。判断依靠语气词、副词。

① ……者，……也。

廉颇者，赵之良将也。

② ……，……也（最常见）

臣之子皆下才也。（《九方皋相马》）

③ ……，……者也

是乃其所以千万臣而无数者也。

④ 乃 / 则 / 即……也（副词加强判断）

若皋之所观，天机也。

⑤ 否定判断：非

非行之谬也（不是做法的错误，《鲁施氏有二子》）

2. 叙述句

动词作谓语，叙述动作事件，内含被动式、双宾语。

（1）被动表示法

王力四种被动句式。

① 于字句：动词 + 于（引出施事，被……）

而窘于贫（被贫穷困迫）

② 为字句：为 + 施事 + 动词

身死人手，为天下笑（被天下人耻笑）

③ 为……所……

若属皆且为所虏（《鸿门宴》，被俘虏）

④ 见 / 见于

诚恐见欺于王而负赵（被大王欺骗）

意念被动（无标记）：先日所用（所用：被采用的道术）

（2）双宾语结构

动词带两个宾语：间接宾语（人）、直接宾语（物）。常见动词：告、语、赐、遗、予。

二子以实告孟氏

完整说法是“告孟氏以实”：告（间接宾语：孟氏）（直接宾语：实）。

公赐之食（《左传》，赐给他食物）

3. 描写句

形容词作谓语，描写性质状态。

孟氏父子舍然无愠容

以形容词性短语描写主语状态。

四、特殊语序

常规语序是主—谓—宾，下面是变式。

1. 宾语前置

王力三大类。

① 否定句，代词作宾语，前置。格式：否定词 + 代词宾语 + 动词。

古之人不余欺也（不余欺 = 不欺余，不欺骗我）

② 疑问句，疑问代词作宾语，前置。

焉往而不穷哉（焉，疑问代词；焉往 = 往焉，去往哪里，《鲁施氏有二子》）

③ 之 / 是 作为提宾标志，把宾语提前。

又何马之能知也（何马之能知 = 能知何马，《九方皋相马》） 唯利是图（唯图利）

2. 介宾短语后置

介词「于、以、乎」构成介宾，本是状语，放在动词或形容词后面，现代汉语要移到前面。

  • 可告以良马 = 可以以良马告之（把识别良马的方法告诉他）
  • 乃有贵乎马者也 = 乃有贵于马者（比马更珍贵）

3. 定语后置

格式 1：中心词 + 之 + 定语 + 者

马之千里者（千里马）

格式 2：中心词 + 者

求人可使报秦者（寻找可以出使回复秦国的人）

4. 谓语前置

主谓倒装，用于感叹、疑问，强调谓语。

败矣，子所使求马者！（正常语序：子所使求马者败矣。你派去找马的人太差劲了！《九方皋相马》） 甚矣，汝之不惠！（《愚公移山》）

五、省略句

上古极普遍，凭上下文补足成分。

  1. 省略主语

    （九方皋）三月而反报曰

    承前省略主语。

  2. 省略宾语（“之”经常省略）

    齐侯纳之，以为诸公子之傅

    以为 = 以（之）为，省略宾语“之”。

  3. 省略介词（于、以）

    将军战河北

    战（于）河北，在黄河以北作战。

  4. 省略谓语

    一鼓作气，再（鼓）而衰，三（鼓）而竭（《曹刿论战》）

六、兼词

一字等于两个词，合音。

  1. 诸 = 之 + 于（之于）

    遂刖之，而还诸鲁 = 还之于鲁，送他回到鲁国

  2. 焉 = 于 + 之（于此，于彼，在这 / 那里）

    三人行，必有我师焉，必有我师于此

  3. 盍 = 何 + 不（何不）

    盍各言尔志？（何不各自说说你们的志向）

七、其他重要句法结构

1. 连动式

同一主语，先后连续多个谓语动作。

孟氏之一子之秦，以术干秦王

主语“一子”，两个连续动作：前往秦国，用道术求秦王任用。

2. 递系式

兼语句：前一动词的宾语，同时是后一分句的主语。

使行求马 = 使（之）行求马

“之”作“使”的宾语，又是“行求马”的主语。

3. “之”取消句子独立性

主谓之间加「之」，使主谓句变成名词性词组，作主语或宾语。

羡施氏之有

原本主谓：施氏有（施氏富有）；加入“之”后成为“施氏之有”，名词短语，充当动词“羡”的宾语。

孤之有孔明，犹鱼之有水也

八、构词

  1. 单音词：一个字一个词。例：禄、爵、穷、谬
  2. 复音词
    • 连绵词（双声、叠韵，不可拆分）：喟然、参差、窈窕。喟然：叠韵连绵，长叹貌。
    • 偏义复词：两个字，词义只取其中一个。例：昼夜勤作息（作息，只取“作”，劳作）
