如何分析一个句子

工具书

1. 字典

解释单个字的形、音、义。

  • 《说文解字》：汉字学史上有划时代的意义，简称《说文》。通过分析字形探索字的本义。独体字叫做文，合体字叫做字；独体字如木、水、火。《说文》首创部首分类法，部首按形体相近原则排列，收录九千多字。

汉字起源

核心问题：什么时候产生、过程如何？假说和推论的依据是什么？

建立汉字起源的依据和推论：

  • 文字是一个民族走向文明的标志。甲骨文已经是很成熟的文字体系，在此之前应已出现更基础的文字，但目前材料不足。
  • 文字克服了时间和空间的限制。
  • 符号与实际意义建立了关联。

《尚书》

《尚书》是儒家经典著作，保存了虞、夏、商、周时期的一些重要史料，相传由孔子选编而成。“尚”即“上”，指上古。

西汉时期，《尚书》有两种传本：

  1. 今文《尚书》：由秦博士伏生传授，共二十九篇，因用汉代通行的隶书写成而得名。
  2. 古文《尚书》：汉武帝末年在孔子旧宅壁中发现，共五十九篇，由孔子的十二代孙孔安国献给朝廷；其中二十九篇内容与伏生传本基本相同，因用战国时期的古文字写成而得名。

西晋永嘉之乱（公元 311 年）后，今、古文《尚书》相继失传。

《尚书》集中反映了上古帝王的统治思想和经验，历代封建统治者多将它作为统治人民的教科书，但其文字比较难懂，所谓“诘屈聱牙”。古代注释家为阅读《尚书》做了许多工作：

  • 最早为《尚书》作注的是孔安国，其注称作《传》。
  • 唐时孔颖达在孔氏基础上进一步作注，其注称作《正义》。
  • 唐以后的注本主要有清人孙星衍的《尚书今古文注疏》等。

古代汉语词汇

古汉语词汇最突出的特点是单音词占优势。它不仅是现代汉语词汇的前身，而且历史悠久、丰富多彩、影响深远，也是汉语词汇研究的重要部分。

词汇分类概览

  • 按结构：单纯词 / 合成词
  • 按音节：单音词 / 多音词
  • 合成词：复合式 / 附加式
  • 多音单纯词：叠音词、连绵字、外来词
  • 复合式：并列式、偏正式、动宾式、主谓式

一、单纯词

单纯词分为单音词和多音词两类。

1. 单音词

现代汉语以双音节词占优势；古代汉语则以单音节词占优势，尤其是先秦文献中，复音词更少。

初，卫宣公烝于夷姜，生急子，属诸右公子。为之娶于齐，而美，公取之。生寿及朔，属寿于左公子。夷姜缢。宣姜与公子朔构急子。公使诸齐，使盗待诸莘，将杀之。寿子告之，使行。急子不可，曰：“弃父之命，恶用子矣？有无父之国则可也。”及行，饮以酒。寿子载其旌以先，盗杀之。急子至，曰：“我之求也，此何罪？请杀我乎！”又杀之。（《左传·桓公十六年》）

本段配套：单音词知识点

  • 古汉语单音词占优势：初、生、娶、美、取、缢、构、使、盗、待、杀、告、行、弃等，大多一字一词。
  • 现代汉语多已改为双音词：当初、生下、迎娶、美丽、夺取、自缢、构陷、派遣、强盗、等候、杀害、告诉、出走、抛弃。

单音词特点

  • 词量大，使用频率高。
  • 义项多、用法灵活、构词能力强。

《左传·宣公十五年》：“初，魏武子有嬖妾，无子。武子疾，命颗曰：‘必嫁是！’疾病，则曰：‘必以为殉！’及卒，颗嫁之，曰：‘疾病则乱，吾从其治也。’”

其中“治”指神志清醒时；若理解成“治病”就错了。

单音词义项多，每一义项都可能与其他相关单音词组成复音词，故构词能力很强。以“中”为例，常见义项如中等、中间、里面、符合、考取等；仅由这几个义项构成的复音词就有几十个，如：中士、中人、中品、中才、中主、中足、中君、中女、中户、中子、中正、中古、中甲、中庸、中道、中年、中行、中界、中心、中央、中流、中宵、中野、中肠、中程、中式、中元、内中、区中、域中、夜中、坐中、国中、梦中、客中、居中、寰中、胸中、洞中、心中、意中、杯中、柔中、桑中、闺中、眼中、考中、正中。

古代连用单音词与现代双音词的区别

古代汉语中两个连用的单音词，很容易被当作现代汉语的双音词，阅读古书时须仔细辨认。例如：

  • 璧有瑕，请指示王。（《史记·廉颇蔺相如列传》）——指示：指给……看
  • 天下云集响应，赢粮而景从。（贾谊《过秦论》）——响应：如响之应
  • 率妻子邑人来此绝境，不复出焉，遂与外人间隔。（陶渊明《桃花源记》）——妻子：妻子和儿女；间隔：隔绝、断绝往来
  • 玉不琢，不成器；人不学，不知道。（《礼记·学记》）——知道：懂得道理
  • 今齐地方千里，百二十城。（《战国策·邹忌讽齐王纳谏》）——地方：土地纵横
  • 墨子者，显学也。其身体则可，其言多而不辩，何也？（《韩非子·外储说左上》）——身体：亲身实践
  • 昨日入城市，归来泪满巾。（张俞《蚕妇》）——城市：城中集市
  • 婉贞于是率诸少年结束而出，皆玄衣白刃。（《冯婉贞》）——结束：整好装束

2. 多音词

单纯词中的多音词主要有三类：叠音词、连绵词、多音节外来词。

（1）叠音词

叠音词是重叠两个相同音节而成的双音节词。用法主要有两种：

描绘形貌

  • 威仪棣棣，不可选也。（《诗·邶风·柏舟》）——棣棣：雍容娴雅的样子
  • 举手长劳劳，二情同依依。（《孔雀东南飞》）——劳劳：忧愁伤感的样子；依依：恋恋不舍的样子

摹拟声音

  • 交交黄鸟，止于棘。（《诗·秦风·黄鸟》）——交交：鸟鸣声
  • 伐木丁丁，鸟鸣嘤嘤。（《诗·小雅·伐木》）——丁丁：伐木声；嘤嘤：鸟鸣声

灼灼状桃花之鲜，依依尽杨柳之貌，杲杲为日出之容，瀌瀌拟雨雪之状，喈喈逐黄鸟之声，喓喓学草虫之韵。皎日嘒星，一言穷理；参差沃若，两字穷形。并以少总多，情貌无遗矣。虽复思经千载，将何易夺。（《文心雕龙·物色》）

更多例句：

  • 河水洋洋，北流活活（guō），施罛濊濊（huò），鱣鲔发发（bō），葭菼揭揭，庶姜孽孽，庶士有朅。（《诗经·卫风·硕人》）
  • 青青河畔草，郁郁园中柳。盈盈楼上女，皎皎当窗牖。娥娥红粉妆，纤纤出素手。（古诗《青青河畔草》）
（2）连绵词

连绵字指由两个音节连缀而成的单纯词，又称“连语”。联绵词是不可分割的整体：两个字只起标音作用，字义与词义无关，写法往往很自由。例如：

  • 匍匐：又作蒲伏、蒲服、匍伏、扶服等
  • 委蛇：又作逶迤、逶移等

分类举例：

  • 双声联绵词：蒹葭、蟋蟀、仿佛
  • 叠韵联绵词：逍遥、殷勤、仓庚、蠨蛸、栗烈、觱发、邂逅、陆离、秋千、踯躅、玄黄、窈窕、憔悴、便嬖、芣苢、薜荔、龟兹
  • 双声叠韵联绵词：辗转、绵蛮、匍匐、缤纷、缱绻
  • 非双声叠韵联绵词：浩荡、滂沱、芙蓉、权舆、跋扈、鹦鹉、狐狸、伎俩、悱恻、狼藉、陵夷、蚯蚓、燕婉、契阔、扶摇、蹂躏、孑孓、栝楼、鹧鸪
（3）外来词

古汉语中的外来词，有的来自中国以外的国家，有的来自国内少数民族语言。例如：苜蓿、葡萄、石榴、琥珀、阎罗、浮屠、涅槃、胡同等。

二、合成词

合成词分为复合式与附加式两类。

1. 复合式

古汉语常见的复合式有并列、偏正、动宾三类，其中偏正式在先秦最多。主谓式在先秦已出现，但数量很少。

（1）并列式

主要包括三种：

  • 近义（含同义）并列：宾客、疆埸、财贿、跋涉、悦怿、褊小、寻常、仓廪、亲戚
  • 对义（含反义）并列：春秋、干戈、刀笔、阴阳、消息、社稷、进退、祸福、乾坤、股肱
  • 偏义并列：国家、妻子、缓急、动静、园圃、车马

偏义复词（偏义并列）：由两个同义、近义、相对或相关的语素构成；在具体语境中，词义只偏落在其中一个语素上，另一个仅作音节陪衬，不承担语义。

  • 车马：偏指车。《礼记·玉藻》：“大夫不得造车马。”
  • 生死：偏指死。林则徐《赴戍登程口占示家人》：“苟利国家生死以，岂因祸福避趋之。”
（2）偏正式

天下、兵法、处士、庶人、百姓、黎民、诸侯、野人、不谷、寡人、先生、国风、布衣、四海、慈母、啬夫、大学、束脩、凉德、尤物、血祭、兵舞、郊祀

（3）动宾式

将军、司寇、司刑、司稼、司城、执事、启明、牵牛、稽首、慎独、掌客、掌畜、免席、勤王、降服、降心

（4）主谓式

肉袒、鸡鸣

2. 附加式

附加式合成词由一个词根加一个词头或词尾构成。古汉语中的词头有“有、言、薄、于”等，例如：

  • 有：有狄、有夏、有戎、有昊、有商、有扈、有穷、有问、有众、有庙
  • 言：言观、言告、言归
  • 薄：薄言、薄浣
  • 于：于征、于思、于飞、于归

（一）旧词的继承

语言中有一部分词能产性强、使用频率高，构成了汉语的基本词汇。旧词的继承可以分为以下两种情况：

1. 古今词形、词义均相同

日、月、星、天、地、人、山、河、东、南、西、北、上、下、左、右、大、小

2. 古今词形相同而词义有别

  • 红：古义浅红；今义泛指各种红色
  • 走：古义跑；今义行走
  • 坐：古义直腰，两膝着地，臀部放在脚跟上；今义直腰，臀部放在坐具上
  • 谢：古义致歉，告罪；今义感谢
  • 病：古义重病；今义泛指各种病
  • 去：古义离开；今义前往
  • 穷：古义窘迫，政治上不得志；今义贫困
  • 百姓：古义百官；今义民众
  • 猖狂：古义无拘束；今义狂妄，放肆
  • 感激：古义感奋激发；今义非常感谢

（二）旧词旧义的消亡

1. 旧词的消亡

原因主要有两个：

（1）词所指称的客观事物已经消亡

如：八佾、大射、劓、刖、臣、媵、奥、台等。

（2）词所指称的事物并没有消亡，但后代的说法改变了
  • 醯 → 醋
  • 绤 → 粗葛布
  • 絺 → 细葛布
  • 屦 → 鞋子
  • 足 → 脚
  • 准 → 鼻子
  • 牡 → 公
  • 牝 → 母
  • 雉 → 野鸡
  • 汲 → 打水
  • 弈 → 下棋
  • 的 → 靶心
  • 速 → 邀请
  • 恙 → 疾病
  • 肩舆 → 轿子
  • 囹圄 → 监狱
  • 侏儒 → 矮子
  • 庠序 → 学校
  • 膏腴 → 肥沃

2. 旧义的消亡

指一些多义词在发展过程中部分义项消亡了。如「数」（《王力古汉语字典》）：

  1. 数目
  2. 几个
  3. 算术
  4. 技艺，技术
  5. 道理，礼数
  6. 命运
  7. 计算，查点
  8. 责备，数说
  9. 屡次，多次
  10. 细密

其中第 4、5、6 三个义项到今天已经消亡。

（三）新词新义的产生

关注点：（一）词义范围不同。

  1. 词义扩大（今大古小）：菜——古指蔬菜，今指各种可吃的东西
  2. 词义缩小（古大今小）：河——古指黄河，今指各种河
  3. 词义转移（今古不同）：羹——古代指用肉（或肉菜相杂）烹煮、带有浓汁的食物；现代常指加入淀粉勾芡、口感稠滑的汤品（如肉羹、花枝羹）

一、词义扩大

  • 江：古义专指长江；今义泛指一切江河
  • 河：古义专指黄河；今义泛指一切河流
  • 器：古义本义陶器；今义泛指一切器具
  • 狗：古义小狗（未成毫者）；今义泛指所有犬类
  • 洗：古义专指洗脚；今义泛指洗涤各类东西
  • 睡：古义上古指坐着打瞌睡；今义一切睡眠（躺着、白天夜晚睡觉）
  • 菜：古义专指蔬菜；今义菜肴（含肉菜）
  • 皮：古义专指兽皮；今义动植物表层外皮
  • 醒：古义专指酒醒；今义一切从昏迷/不清醒恢复清醒

二、词义缩小

  • 宫：古义一切房屋、居室；今义帝王宫殿
  • 瓦：古义所有陶制器物；今义屋顶瓦片
  • 金：古义金属总称（五色金）；今义专指黄金
  • 子：古义子女，兼指儿子、女儿；今义专指儿子
  • 禽：古义鸟兽总称；今义仅鸟类
  • 臭（xiù）：古义一切气味（香、臭都叫臭）；今义难闻的臭味

三、词义转移

  • 涕：古义眼泪；今义鼻涕
  • 脚：古义小腿（胫）；今义足部，脚丫
  • 汤：古义热水、开水；今义菜汤、肉汤
  • 闻：古义听见（听觉）；今义用鼻子嗅（嗅觉）
  • 坟：古义大土堆、河堤；今义坟墓
  • 兵：古义兵器、武器；今义士兵、军队
  • 羹：古义带汁的肉（肉羹）；今义糊状汤羹
  • 暂：古义突然、一下子；今义暂时、短暂
  • 行李：古义外交使者；今义出行携带的包裹物品

（四）词语感情色彩改变

古褒今贬、古贬今褒、古中性今变（变褒 / 变贬）。

一、古褒今贬

  • 爪牙：古义武臣、君主得力辅佐之人（褒义）；今义坏人的帮凶、走狗（贬义）。《汉书》：将军者，国之爪牙也。
  • 明哲保身：古义通达事理，智慧自保（褒义）；今义回避原则、只顾自保（贬义）。《诗经》：既明且哲，以保其身。
  • 复辟：古义失位君主重新复位（中性偏褒）；今义反动势力卷土重来（贬义）。《明史》：奉英宗复辟。

二、古贬今褒

  • 锻炼：古义罗织罪名、诬陷害人（贬义）；今义磨炼身心、提升能力（褒义）。《后汉书》：锻炼之吏，持心近薄。

三、古中性，后世色彩发生变化

① 古中性 → 今贬义
  • 谤：古义公开议论、批评君主过失（中性）；今义造谣污蔑、恶意中伤（贬义）。《国语》：国人谤王；《邹忌讽齐王纳谏》：能谤讥于市朝。
  • 卑鄙：古义卑＝地位低下，鄙＝见识浅陋，自谦（中性）；今义人品卑劣恶劣（贬义）。《出师表》：先帝不以臣卑鄙。
② 古中性 → 今褒义
  • 祥：古义吉凶两种征兆（中性）；今义专指吉祥（褒义）。《左传》：是何祥也？吉凶焉在？

（五）词义程度变化

分为两类：词义加重（今义 > 古义）、词义减轻（今义 < 古义）。

一、词义加重

  • 诛：古义责备、批评（口头谴责）；今义杀戮，诛杀，处死。先秦“诛”多指指责，杀人多用“杀”。例：《论语》“于予与何诛”，是责备宰予，不是杀他。
  • 谤：主要是感情色彩变化，也附带程度加重——古义公开议论批评（轻）；今义恶意造谣诋毁（重）。

二、词义减轻

  • 购：古义重金悬赏、重金征求；今义购买，普通买卖。古义是高价悬赏捉拿/求取；今天普通花钱买东西，词义变轻。
  • 怨：古义痛恨、怨恨（程度很深）；今义埋怨、不满（轻微责怪）。先秦“怨”是深仇；今只是小小的不满。例：《史记》“秦人大怨”是痛恨。
  • 感激：古义感动奋发，内心强烈触动（往往伴随奋发立志）；今义感谢，一般的谢意。古义情绪强烈；现在只是礼貌道谢，程度变轻。

（六）本义和引申义

什么是词的本义

所谓本义，是指造字时所采用的意义，而不一定指词最原始的意义。我们今天所说的本义是相对的，通常指造字时代所采用的意义，以及文献史料所能证明的最早意义。

举例：

  • 向：本义朝北的窗户；引申义朝着、面向。例：《诗经》塞向墐户
  • 道：本义道路；引申义途径、方法、道理、学说。例：道阻且长；朝闻道，夕死可矣
  • 兵：本义兵器、武器；引申义士兵、军队、战争。例：收天下之兵
  • 本：本义树根；引申义根本、基础、本来。例：木下曰本
  • 行：本义道路（象形）；引申义行走、实行、品行。例：遵彼微行
  • 解：本义解剖、分割牛体；引申义解开、解除、消散、理解。例：庖丁解牛
  • 字：本义生孩子；引申义文字（乳 → 孳生，文字孳乳）。例：女子贞不字
  • 叔：本义拾取；引申义叔父。例：九月叔苴

二、引申义分类

引申义分为直接引申与间接引申。

（1）直接引申（辐射式引申）

由本义直接派生出来的意义；多个引申义都以本义为中心向外辐射，彼此不一定有关系。

例：节

  • 本义：竹节
  • 直接引申：
    1. 木节
    2. 人的关节
    3. 符节（信物，分段）
    4. 节气
    5. 礼节
    6. 节制
    7. 节操

比喻引申依靠事物相似性形成新义，一般也属于直接引申。

（2）间接引申（连锁式引申）

不是从本义直接生出，而是由已有的引申义再继续引申，一环扣一环，辗转衍生。

例：朝

  • 本义：早晨
  • 直接引申：朝见（早晨拜见君王）
  • 间接引申：朝廷（朝见之处）→ 朝代（朝廷统治的时代）

「朝代」不是直接来自「早晨」，而是经过中间环节辗转引申出来的。
