## 《鲁施氏有二子》

鲁施氏有二子，其一好学，其一好兵。好学者以术干齐侯；齐侯纳之，以为诸公子之傅。好兵者之楚，以法干楚王；王悦之，以为军正。禄富其家，爵荣其亲。

施氏之邻人孟氏，同有二子，所业亦同，而窘于贫。羡施氏之有，因从请进趋之方。二子以实告孟氏。孟氏之一子之秦，以术干秦王。秦王曰：“当今诸侯力争，所务兵食而已。若用仁义治吾国，是灭亡之道。”遂宫而放之。

其一子之卫，以法干卫侯。卫侯曰：“吾弱国也，而摄乎大国之间。大国吾事之，小国吾抚之，是求安之道。若赖兵权，灭亡可待矣。若全而归之，适于他国。为吾之患不轻矣。”遂刖之，而还诸鲁。

既反，孟氏之父子叩胸而让施氏。施氏曰：“凡得时者昌，失时者亡。子道与吾同，而功与吾异，失时者也，非行之谬也。且天下理无常是，事无常非。先日所用，今或弃之；今之所弃，后或用之。此用与不用，无定是非也。投隙抵时，应事无方，属乎智。智苟不足，使若博如孔丘，术如吕尚，焉往而不穷哉？”孟氏父子舍然无愠容，曰：“吾知之矣，子勿重言！”

### 重点词汇

- **干（gān）**：干谒，求仕
- **之**：动词，往、到；代词；结构助词
- **让**：责备（≠谦让）
- **诸**：兼词，之于
- **反**：通“返”，返回
- **摄**：夹
- **窘**：困迫
- **务**：致力
- **穷**：困厄，走投无路（不是贫穷）
- **或**：或许

### 重点语法

1. **使动用法**
   - 禄富其家、爵荣其亲：富、荣，形使动
   - 全而归之：全，形使动
2. **判断句**：吾弱国也；失时者也，非行之谬也。（“也”字判断，“非”表否定判断）
3. **被动句**：窘于贫（于引介被动）
4. **宾语前置**
   - 大国吾事之（强调宾语前置）
   - 焉往而不穷（疑问代词宾语前置）
5. **所字结构、者字结构**：所业、所务；好学者、得时者
6. **兼词**：诸 = 之于；乎 = 于
7. **通假字**：反 = 返；舍 = 释

## 《九方皋相马》

秦穆公谓伯乐曰：“子之年长矣，子姓有可以求马者乎？”伯乐对曰：“良马可形容筋骨相也。天下之马者，若灭若没，若亡若失，若此者绝尘弭辙，臣之子皆下才也，可告以良马，不可告以天下之马也。臣有所与共担纆薪菜者，有九方皋，此其于马非臣之下也。请见之。”

穆公见之，使行求马，三月而反报曰：“已得之矣，在沙丘。”穆公曰：“何马也？”对曰：“牝而黄。”使人往取之，牡而骊。

穆公不说，召伯乐而谓之曰：“败矣，子所使求马者！色物牝牡尚弗能知，又何马之能知也？”伯乐喟然太息曰：“一至于此乎！是乃其所以千万臣而无数者也。若皋之所观，天机也，得其精而忘其粗，在其内而忘其外；见其所见，不见其所不见，视其所视，而遗其所不视。若皋之相者，乃有贵乎马者也。”

马至，果天下之马也。

### 重点词汇

- **子姓**：子孙后辈（≠姓氏）
- **形容**：形体外貌（古今异义）
- **相（xiàng）**：鉴别，观察
- **纆**：绳索；薪菜：采薪，菜通采
- **见（xiàn）**：使……谒见，使动
- **反**：通“返”；说：通“悦”
- **牝**：母；牡：公；骊：纯黑
- **太息**：长叹
- **所以**：……的缘故 / ……的地方
- **遗**：舍弃

### 重点语法

1. **介宾短语后置**
   - 可告以良马 → 可〔以良马〕告之
   - 贵乎马 → 贵于马
2. **宾语前置**：何马之能知，“之”作提宾标志
3. **谓语前置（感叹倒装）**：败矣，子所使求马者！
4. **判断句（也 / 乃）**：臣之子皆下才也；若皋之所观，天机也；果天下之马也；是乃其所以千万臣而无数者也。
5. **所字结构、者字结构**：所与共担纆薪菜者、所使求马者、所见、所不见
6. **通假字**：反 = 返；说 = 悦；菜 = 采
7. **使动用法**：请见之，使之见（使九方皋谒见穆公）

所字结构的定义和例句见 [所字结构](/articles/books/classical-chinese/1-1.html)。

## 《景公射出质》

晏子没十有七年，景公饮诸大夫酒。公射出质，堂上唱善，若出一口。公作色太息，播弓矢。

弦章入，公曰：“章！自吾失晏子，于今十有七年，未尝闻吾过不善。今射出质，而唱善者若出一口。”弦章对曰：“此诸臣之不肖也：知不足以知君之不善，勇不足以犯君之颜色。然而有一焉，臣闻之：君好之，则臣服之；君嗜之，则臣食之。夫尺蠖食黄则其身黄，食苍则其身苍。君其犹有食谄人之言乎！”

公曰：“善！今日之言，章为君，我为臣。”

是时，海人入鱼，公以五十乘赐弦章。章归，鱼乘塞涂。抚其御之手曰：“曩之唱善者，皆欲若鱼者也。昔者，晏子辞赏以正君，故过失不掩。今诸臣谄谀以干利，故出质而唱善如出一口。今所辅于君未见于众，而受若鱼，是反晏子之义而顺谄谀之欲也。”固辞鱼不受。

君子曰：“弦章之廉，乃晏子之遗行也。”

### 重点词汇

- **没（殁）**：死亡；有（又），整数零数之间
- **饮（yìn）**：使动，使……饮酒
- **太息**：长叹
- **知（智）**：通假，智慧
- **颜色**：脸色、威严（古今异义）
- **干（gān）**：求取（干利）
- **曩**：先前
- **涂（途）**：道路
- **御**：车夫
- **固**：坚决

### 重点语法

#### 通假字

- 没 = 殁；十有七年，有 = 又；知 = 智；涂 = 途

#### 词类活用

1. 饮诸大夫酒：动词**使动**，使……饮
2. 晏子辞赏以正君：形容词**使动**，正君 = 使君正，匡正君主

#### 者字结构（V + 者）

- 唱善者：叫好的人；欲若鱼者：想要这些鱼的人

#### 所字结构

- 所辅：所辅佐（的成效）

#### 判断句

1. 此诸臣之不肖也（……，……也）
2. 曩之唱善者，皆欲若鱼者也（……者，……也）
3. 是反晏子之义而顺谄谀之欲也
4. 弦章之廉，乃晏子之遗行也（乃……也）

#### 被动句

1. 过失不掩：意念被动，过失不被掩盖
2. 未见于众：**见 + 于**被动句式（王力四大被动之一，被众人看见）

#### “之”取消句子独立性

- 君之不善；弦章之廉

#### 兼词

- 焉：有一焉，于此，在这里

#### 双宾语

- 公以五十乘赐弦章：赐（间接宾语：弦章）（直接宾语：五十乘鱼）

#### 连动句

- 公作色太息，播弓矢（同一主语，连续动作）

#### 省略句

多处省略主语、宾语（之）。

### 古代文化常识

1. **职官等级**：诸侯下面分卿、大夫、士；大夫为国君高级臣僚。
2. **礼制：燕礼、燕射**。国君闲暇宴群臣，席间燕射，射礼重在观德，不只是竞技。
3. **车马**：一乘 = 一车四马；御 = 车夫。
4. **贡赐制度**：地方献特产叫入 / 贡；上给予下叫赐。
5. **先秦谏议与讽谏**：臣子委婉比喻规劝君主；君主纳谏为美德。
6. **思想观念**：上行下效；义利之辨，无功不接受赏赐，士大夫清廉操守。
7. **文体习惯**：“君子曰”是先秦评议人物的固定写法。
8. **六艺**：贵族必修礼、乐、射、御、书、数。

## 《原宪居鲁》

原宪居鲁，环堵之室，茨以生草，蓬户不完，桑以为枢而瓮牖，二室，褐以为塞，上漏下湿，匡坐而弦。

子贡乘大马，中绀而表素，轩车不容巷，往见原宪。原宪华冠縰履，杖藜而应门。

子贡曰：“嘻！先生何病？”原宪应之曰：“宪闻之：‘无财谓之贫，学而不能行谓之病。’今宪，贫也，非病也。”子贡逡巡而有愧色。

原宪笑曰：“夫希世而行，比周而友，学以为人，教以为己，仁义之慝，舆马之饰，宪不忍为也。”

### 重点词汇

- **环堵**：四面围墙，一丈见方的小屋。环，环绕；堵，土墙，一丈为一堵
- **茨（cí）**：用草盖屋顶
- **蓬户**：蓬草编的门
- **枢（shū）**：门轴
- **瓮牖（wèng yǒu）**：用破瓮做的窗户
- **褐（hè）**：粗麻布，粗布衣服
- **匡坐**：正坐，端坐
- **弦**：弹琴，鼓琴
- **绀（gàn）**：红青色，深青带红的颜色
- **轩车**：有帷幕、较高的贵族大车
- **华冠**：破旧的帽子；华，通“花”，破烂
- **縰（xǐ）履**：无后跟的鞋，草鞋
- **杖藜**：拄着藜木拐杖；杖，名词作动词，拄
- **逡巡（qūn xún）**：退却，局促不安的样子
- **希世**：迎合世俗。希，通“晞”，求，迎合
- **比周**：结党营私，互相勾结
- **慝（tè）**：邪恶，奸邪
- **舆马**：车马

### 重点语法

#### 通假字

- 华 = 花，破旧；希 = 晞，迎合、求取

#### 词类活用

1. **桑以为枢**：名词作动词，桑（木），用桑木做
2. **杖藜而应门**：名词作动词，杖，拄着
3. **匡坐而弦**：名词作动词，弦，弹琴、鼓琴

#### 者字结构

本篇无典型者字结构。

#### 所字结构

本篇无典型所字结构。

#### 判断句

1. 无财谓之贫，学而不能行谓之病（谓字判断句）
2. 今宪，贫也，非病也（……，……也；否定判断“非”）

#### 被动句

本篇无王力四类典型被动，无意念被动。

#### “之”取消句子独立性

本篇无“之”取独。

#### 兼词

本篇无兼词。

#### 双宾语

本篇无双宾语。

#### 连动句

1. 杖藜而应门：同一主语，拄藜杖、开门，连续动作
2. 子贡逡巡而有愧色：子贡退后，面露惭愧之色，连动

#### 省略句

1. 茨以生草：省略宾语，茨（室）以生草，用野草盖屋顶
2. 桑以为枢：桑以（之）为枢，用桑木做门轴
3. 褐以为塞：褐以（之）为塞，用粗麻布当作堵塞缝隙之物

#### 介宾短语后置（状语后置）

1. **茨以生草** → 以生草茨，用野草覆盖屋顶
2. **桑以为枢** → 以桑为枢

### 古代文化常识

1. **原宪、子贡**：孔门弟子。原宪（子思），安贫乐道；子贡（端木赐），善于经商，富有，擅长外交。出自《庄子》，体现儒家、道家共同推崇的君子人格。
2. **居室名物**：环堵、蓬户、瓮牖。上古平民简陋居所；贵族居住高堂大屋，贫富居所差异巨大。
3. **服饰礼制**：古人上衣下裳；绀、素是古代服色。贵族乘车穿华美的衣服，粗褐是底层百姓、隐士的粗麻布衣服。
4. **车马制度**：轩车，高级贵族所乘的有篷高车（王力车马篇），和普通马车区分，是身份象征。
5. **士的操守**：先秦“贫”和“病”的区分。**贫**是缺少财物；**病**是学问道德不能践行。安贫乐道，是孔门君子核心修养。
6. **比周**：先秦政治术语，结党勾结。《论语》“君子周而不比，小人比而不周”。
7. **希世（媚俗）**：先秦士人两种人生选择：一是迎合世俗、追名逐利；一是守道安贫，不慕荣华。
8. **弦**：古代士人的修养，弹琴（乐）属于贵族六艺“乐”。
