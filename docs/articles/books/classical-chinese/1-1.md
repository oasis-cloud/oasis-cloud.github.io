## 定义

> **“所”是一个特殊指示代词，放在动词（或动词性词组）前面，构成「所 + V」，叫做所字结构。所字结构整体是名词性短语，在句子里充当主语、宾语、定语。**

核心一句话：**“所 + 动词” ≈ “……的人 / ……的事物 / ……的地方”**。

## 一、基本格式

### 1. 所 + 及物动词

公式：**所V = 所V的对象**。

- 所见 = 看见的东西
- 所闻 = 听到的事
- 所务 = 致力的事情（上文中：所务兵食而已）

王力强调：**“所”本身不独立充当句子成分；它必须依附动词，组合之后整个短语才是名词性。**

和者字结构的区别：

- **者字结构**是 **V + 者**，指做这个动作的人。见者：看见的人。
- **所字结构**是 **所 + V**，指被这个动作涉及的东西。所见：被看见的东西。

### 2. 所 + 动词 + 者（所……者）

“者”起复指作用，加强指代，整体仍然名词性。

> 所与共担纆薪菜者（《九方皋相马》）= 和我一起扛绳打柴的那个人

### 3. 所 + 介词 + 动词

所从、所由、所以是王力重点。

- **所以**：不是现代汉语“因此”。古汉语表示“用来……的工具 / 方法；……的原因”。
  - 是乃其所以千万臣而无数者也（《九方皋相马》）→ 这就是他胜过我千万倍的地方 / 原因。
- **所从**：从哪里
- **所由**：经由的途径

### 4. 所 + 形容词

少见，形容词活用为动词。所贵：看重的东西。

## 二、语法功能

所字结构在句中当名词用。

1. **作主语**

   > 先日所用，今或弃之（《鲁施氏有二子》）

   原先被采用的（道术），现在或许舍弃。「所用」作主语。

2. **作宾语**

   > 羡施氏之有（《鲁施氏有二子》）

   “有”活用为动词，所有 = 拥有的财富。羡：羡慕，宾语是“施氏之所有”。

3. **作定语**

   后面加名词，格式是「所V + 之 + 名词」。

   > 所食之粟：吃的粮食
   > 所居之屋：居住的房屋

   此时“所V”修饰名词，“所”指代这个名词。

## 三、关键特点

1. **所字结构自带被动意味**

   `所V` 大多是“被V的事物”。

   > 所用：被使用的东西（不是“去使用的人”）

   对比：用者 = 使用的人。

2. **动词前有施事者时，用介词“与 / 以”引出**

   > 所与共担纆薪菜者：「与」是介词，和（我）。

   所与V：和……一起做某事的人。

3. **所字结构不能单独作谓语**（因为是名词性）

   - 所见甚多。（所见：主语）
   - 吾所见：不能直接当谓语，谓语要用判断句，如“是吾所见也”。

## 四、所字结构与者字结构

| 结构 | 格式 | 含义 | 侧重点 |
| --- | --- | --- | --- |
| **所字结构** | 所 + 动词 | 所V的**事物**（受事，被动作作用的对象） | **动作的对象** |
| **者字结构** | 动词 + 者 | V的**人**（施事，发出动作的人） | **动作发出者** |

- 见者：看见的人（发出“看”的人，者字结构）
- 所见：看见的事物（被看到的东西，所字结构）
- **所见者** = 所看见的东西（所 + V + 者，“者”复指）

## 五、课文例句

1. **所业亦同**（《鲁施氏有二子》）

   > 所业：所学的东西。所 + 动词“业”（治学），名词性短语。

2. **所务兵食而已**（《鲁施氏有二子》）

   > 所务：所致力的事务。主语。

3. **子所使求马者**（《九方皋相马》）

   > 所使：所派遣（的人）。所 + 动词“使”；后面再加“者”。所使求马者：被派去找马的人。

4. **若皋之所观，天机也**（《九方皋相马》）

   > 所观：所观察到的（东西、本质）。主语。

## 六、简答背诵

> “所”是特殊指示代词，置于动词或动词性词组前，构成**所字结构**，整体为名词性短语，在句中充当主语、宾语、定语，表示“……的人 / 事物 / 地方”；多含被动意味，指代动作的对象。常和“者”配合使用。
