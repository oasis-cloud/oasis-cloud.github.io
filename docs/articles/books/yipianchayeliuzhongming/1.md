听得最多的是绿茶和红茶，但并不很清楚它们之间的差异。通过这本书，我了解到茶叶的品类是根据制作工艺进行区分的。下面整理了几种品类的工艺流程和冲泡特点。

## 工艺流程

| 茶类 | 工序 | 关键控制点 |
| ---- | ---- | ---------- |
| 绿茶 | 杀青、揉捻、干燥 | 高温杀青终止酶活性，保留「清汤绿叶」 |
| 白茶 | 萎凋、干燥 | 适度萎凋让部分多酚氧化，形成清甜，日晒或文火干燥定型 |
| 黄茶 | 杀青、揉捻、闷黄、干燥 | 闷黄是黄茶独有工序，使叶底与汤色变黄，滋味柔和 |
| 青茶（乌龙茶） | 晒青 / 萎凋 → 摇青 → 半发酵 → 杀青 → 整形 → 干燥 | 叶缘细胞破损率高，形成「绿叶红镶边」，香气多变 |
| 红茶 | 杀青 → 揉捻 → 全发酵 → 干燥 | 发酵使茶黄素、茶红素形成，汤色红亮 |
| 黑茶 | 杀青 → 揉捻 → 后发酵（微生物参与） → 干燥 | 通过微生物转化，汤味更醇厚，可长期陈化 |

## 冲泡差异

### 水温

- **绿茶、黄茶**：$80$–$85\,\mathrm{℃}$，避免烫坏嫩叶。
- **白茶**：$90$–$100\,\mathrm{℃}$，较高水温有助于释放毫香。
- **乌龙茶、黑茶**：$100\,\mathrm{℃}$ 沸水，高水温可充分展香，黑茶也可煮饮。

### 器具

- **绿茶**：玻璃杯、盖碗，便于观赏芽叶舒展。
- **白茶**：盖碗或玻璃杯，慢冲慢出以保毫香。
- **黄茶**：玻璃杯或盖碗，冲泡方法近似绿茶。
- **乌龙茶**：小紫砂壶、盖碗或潮汕工夫壶，高冲刮沫后低斟分茶。
- **红茶**：瓷杯、玻璃杯或壶，$90$–$100\,\mathrm{℃}$ 冲泡即可。
- **黑茶**：紫砂壶、陶壶或公道杯，紧压茶需先醒茶、润茶。

### 投茶量与茶水比

- **绿茶**：$1$–$2\,\mathrm{g}/150\,\mathrm{mL}$
- **白茶**：$3$–$5\,\mathrm{g}/150\,\mathrm{mL}$
- **黄茶**：$3$–$5\,\mathrm{g}/150\,\mathrm{mL}$
- **乌龙茶**：壶容积 $1/2$–$2/3$，约 $10\,\mathrm{g}/100\,\mathrm{mL}$
- **红茶**：$1\,\mathrm{g}/50\,\mathrm{mL}$
- **黑茶**：$5$–$10\,\mathrm{g}/100\,\mathrm{mL}$（视茶质与年份）

## 浸泡时间与冲泡次数

| 茶类 | 第一泡 | 第二泡 | 第三泡 | 典型冲泡次数 |
| ---- | ------ | ------ | ------ | ------------ |
| 绿茶 | $2$–$3\,\mathrm{min}$ | — | — | $2$–$3$ 次即可 |
| 白茶 | $3$–$5\,\mathrm{min}$ | $5$–$7\,\mathrm{min}$ | $7$–$10\,\mathrm{min}$ | $3$–$5$ 次 |
| 黄茶 | $2$–$4\,\mathrm{min}$ | $4$–$6\,\mathrm{min}$ | $6$–$8\,\mathrm{min}$ | $3$–$4$ 次 |
| 乌龙茶 | $1$–$2\,\mathrm{min}$ | $2$–$3\,\mathrm{min}$ | $3$–$4\,\mathrm{min}$ | $5$–$6$ 次，耐泡 |
| 红茶 | $3$–$5\,\mathrm{min}$ | $5$–$7\,\mathrm{min}$ | $7$–$10\,\mathrm{min}$ | $3$–$4$ 次 |
| 黑茶 | 洗茶后快速出汤，随后逐次延长 | — | — | $10$ 次以上，可煮泡 |
