## 镜头透视

- **广角镜头和扩展空间**
- **深焦**：前景、中景、背景都保持清晰。摄影师把选择权更多交给观众。
- **空间压缩**：长焦镜头最容易产生这种感觉。

真实空间：

```text
A ---------------------- B
近                       远

A ---- B
看起来很近
```

前景和背景之间的距离感被压缩。广角可以拉深空间感。

- **操纵视角**
- **选择性对焦**：摄影师替观众决定看哪里。

| 镜头方法   | 改变什么感觉           |
| ---------- | ---------------------- |
| 广角       | 空间展开               |
| 长焦       | 空间压缩               |
| 深焦       | 让多个空间层次都重要   |
| 选择性对焦 | 指定观众注意力         |
| 操纵视角   | 改变空间关系和人物比例 |
