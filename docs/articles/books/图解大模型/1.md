## 因果掩码

通过 Q 和 K 得到一个注意力分数矩阵，现在需要把未来的分数屏蔽掉。被屏蔽的位置填入 负无穷。

之所以填入负无穷是因为在 softmax 计算时，e^负无穷 是 0，也就是权重归一化之后为 0。

## 残差链接与层归一化

如果 Transformer 有几十层甚至上百层，每一层都对向量进行一次复杂变换，信息会不会在层层计算中丢失？训练会不会越来越困难？

残差连接：不要每一层都从头构造结果

它的公式是：
\[
\boxed{y=x+F(x)}
\]
为什么这样设计？
主要有两个原因。

1. 保留信息的直通路径

即使某个计算模块只产生了很小的变化，原来的表示仍然可以通过相加路径传递下去。

2. 改善深层网络的梯度传播

训练神经网络时，需要通过反向传播计算梯度。

假设：
\[
y=x+F(x)
\]

那么对输入 \(x\) 求导：
\[
\frac{dy}{dx}=1+\frac{dF(x)}{dx}
\]

这里的 \(1\) 是关键。

即使 \(F(x)\) 这条路径的梯度很小，仍然存在一条直接的梯度传递路径。这有助于缓解深层网络训练中的梯度传播困难。
它究竟对什么进行归一化？
先记住一个关键点：

在 Transformer 中，LayerNorm 通常针对每个 Token 自己的特征向量进行归一化，而不是把一句话里的所有 Token 混在一起计算。

例如：

「小明喜欢打球」经过 Embedding 和后续计算后，假设有四个 Token，每个 Token 的向量维度为 3：
\[
X=
\begin{bmatrix}
1&2&3\\
2&4&6\\
3&6&9\\
4&8&12
\end{bmatrix}
\]

这是一个 \(4\times3\) 的矩阵：

- 4：Token 数量。
- 3：每个 Token 的特征维度。
  LayerNorm 会分别处理每一行。

例如第二行：
\[
x=[2,4,6]
\]

它不会拿第一行、第三行、第四行的数据来计算这一行的均值和方差。2. 第一步：计算均值
公式：
\[
\mu=\frac{x_1+x_2+\cdots+x_n}{n}
\]

代入：
\[
\mu=\frac{2+4+6}{3}=4
\]

也就是说，这个向量的平均值是 4。3. 第二步：计算方差
方差用于衡量各个数值与平均值之间的偏离程度。

公式：
\[
\sigma^2=\frac{1}{n}\sum\_{i=1}^{n}(x_i-\mu)^2
\]

代入：
\[
\begin{aligned}
\sigma^2
&=\frac{(2-4)^2+(4-4)^2+(6-4)^2}{3}\\
&=\frac{4+0+4}{3}\\
&=\frac{8}{3}
\end{aligned}
\]

标准差就是方差开平方：
\[
\sigma=\sqrt{\frac83}\approx1.633
\]

4. 第三步：标准化
   把每个数值减去均值，再除以标准差：
   \[
   \hat{x}\_i=\frac{x_i-\mu}{\sigma}
   \]

逐个计算：
\[
\begin{aligned}
\hat{x}\_1&=\frac{2-4}{1.633}\approx-1.225\\
\hat{x}\_2&=\frac{4-4}{1.633}=0\\
\hat{x}\_3&=\frac{6-4}{1.633}\approx1.225
\end{aligned}
\]

因此：
\[
[2,4,6]\longrightarrow[-1.225,0,1.225]
\]
可学习的缩放和平移
真实的 LayerNorm 还包含两个可学习参数：

- \(\gamma\)：控制缩放程度。
- \(\beta\)：控制平移程度。
  完整公式：
  \[
  \boxed{
  LN(x)=\gamma\odot
  \frac{x-\mu}{\sqrt{\sigma^2+\epsilon}}
  +\beta
  }
  \]

这里：

- \(\epsilon\)：一个很小的数，避免分母为零。
- \(\odot\)：逐元素相乘。
- \(\gamma,\beta\)：模型训练过程中学习得到的参数。
  为什么归一化后还要允许缩放和平移？

因为模型不一定希望每个特征始终保持均值为 0、方差为 1。归一化提供稳定的数值基础，而可学习参数允许模型调整适合自己的数值范围。
