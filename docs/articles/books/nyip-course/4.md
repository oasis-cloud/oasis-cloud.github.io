## 好照片的标准

1. 清晰
2. 曝光良好
3. 色调范围：黑白照片应该有很宽的色域，从最黑到最白
4. 反差

彩色照片还应该具备：

1. 色彩逼真度
2. 色彩饱和度
3. 色彩平衡
4. 色彩反差

## 人体魅态摄影

核心仍然是：如何通过光线、姿态、构图，把人体的形态表现出来。

### 姿态

人体摄影不是简单地让模特「站好」，而是利用身体的曲线、重心、四肢方向、身体扭转，形成视觉线条。

### 光线

光线决定人体的立体感。例如：

- 正面光 → 身体比较平
- 侧光 → 肌肉、曲线、凹凸更加明显
- 逆光 → 强调轮廓

## 广告摄影与静物摄影

广告摄影到底拍什么？让观众产生购买或向往这个东西的欲望。

静物摄影的本质，是控制物体周围的光线，让物体呈现你想要的质感。

## 建筑摄影

核心：如何控制「空间的形状」。

建筑摄影最大的敌人是透视。透视投影改变了三维空间在二维照片中的形状。

建筑摄影的核心不是把建筑拍全，而是控制照片中的空间和透视关系。

## 新闻摄影

发生的事情中，什么最值得让别人知道？判断什么具有新闻价值。

优秀新闻照片通常同时解决两个问题：

1. 发生了什么？
2. 为什么重要？

比如一个人摔倒：

- 普通照片：一个人躺在地上。
- 新闻照片：通过人物、环境、动作，让你知道「为什么他会在那里」。

所以新闻摄影要求信息密度。
