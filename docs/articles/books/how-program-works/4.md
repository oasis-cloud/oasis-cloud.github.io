### 如何将程序从磁盘加载进内存

对于 c 程序，编译后可得到一个`.out`的文件，该文件在 Linux 中是按照 ELF 规范生成的。

程序加载器会读取 ELF 标准的文件，解析 Program Headers，操作系统为该文件程序分配虚拟地址空间。

分配虚拟地址空间，不代表程序被完整的加载进内存，当第一次访问某页时，如果该页不在物理内存中，CPU会触发缺页异常，内核进行处理，检测访问合法性、从磁盘读取或复用缓存等。更新页表，并重新执行指令。
