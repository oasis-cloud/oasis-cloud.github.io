## 古汉语语法研究简况

马建忠《马氏文通》（1898）用西方语法学框架系统描写汉语，是古汉语语法研究进入现代阶段的里程碑。主要贡献：

1. 用语法学方法描写汉语。
2. 确立实词、虚词的词类体系。
3. 归纳汉语的主要语法结构。

### 二十世纪前五十年

重要著作：《中等国文典》《中国文法通论》《国文法之研究》《国文法草创》《词诠》《古书虚字集释》《比较文法》《中国文法语文通解》《中国文法要略》《中国文法论》《中国语法理论》《汉语语法论》等。吕叔湘《中国文法要略》影响很大。

### 二十世纪后五十年

研究队伍扩大，方法更新；范围从文言扩展到近代汉语、方言、汉藏语比较。吕叔湘是近代汉语分析体系的开创者之一。王力《汉语史稿》是语法史研究的开山之作。台湾周法高《中国古代语法》。杨伯峻注释《左传》等书，兼有语法说明。

研究方向大致三类：

1. **历时研究**：断代语法与汉语史。起步早、成就突出的如管燮初《殷虚甲骨刻辞的语法研究》《西周金文语法研究》；另有陈梦家、刘世儒、柳士镇，以及杜百胜、志村良治等海外学者的断代著作。
2. **专书研究**：如杜百胜《诗经语法》、许世瑛《论语二十篇句法研究》、何乐士《左传虚词研究》、向熹《诗经语言研究》、吴福祥《敦煌变文语法研究》等。
3. **专题研究**：某一词类、句式或方言现象的专题论文与专著。

研究方法上，材料统计（穷尽式）很常见。注意：统计量大不等于理解准确，结论仍依赖对文献的准确解读。

## 名词、动词、形容词、数量词

### 一、名词

表示人或事物名称的词。作主语、宾语、定语；也可活用为动词、作状语（见词类活用）。

常见类别：

- **普通名物**：天、地、日、月、人、山、水、牛、马
- **抽象概念**：仁、义、礼、道、德、阴阳
- **方位时间**：上、下、内、外、东、西、南、北、中；今、昔、时、夜、旦、暮
- **职官身份**：公、侯、伯、子、男；天子、诸侯、司寇、陪臣
- **专名**：秦穆公、齐桓公、城濮、鄢陵

> 齐侯纳之，以为诸公子之傅（《鲁施氏有二子》）——侯、公子、傅，名词。

上古名词前可加词头“有”，如有夏、有虞、有穷（见 [词汇笔记](/articles/gu-dai-han-yu/2.html) 附加式）。

### 二、动词

表示动作、行为、存在、变化或心理活动。《马氏文通》称“动字”。主要作谓语，也可作主语、宾语、定语等。

- **动作行为**：攻、伐、杀、见、闻、取、射
- **心理活动**：爱、恶、畏、惧、恐、思、恨
- **存在变化**：有、无、生、死、存、在
- **能愿**：可、能、欲、忍

与现代汉语不同的是：动词常有**使动用法**，也可直接放在另一动词前作状语（如“趋而避之”一类），详见词类活用。

> 孟氏之一子之秦，以术干秦王——干：干谒；之：前往（动词“之”≠助词）。

### 三、形容词

表示性质、状态。《马氏文通》称“静字”。主要作定语、谓语，也可作主语、宾语、状语、补语。

- **性质**：善、良、美、智、愚、强、弱、高、厚、薄
- **状态叠音 / 连绵**：依依、灼灼、穆穆、窈窕、参差
- **带词尾**：铿尔、沃若、跃如、俨然、恢恢乎（然、如、若、尔、乎为词尾）

形容词词头看法不一；有人把“其黄”“有炜”中的“其”“有”看作词头。

> 孟氏父子舍然无愠容——愠：恼怒。

形容词也常有使动、意动用法。

### 四、数量词

#### 1. 数词

基数、序数、分数、约数、虚数。上古数词可直接修饰名词，中间常不用量词。

- **基数**：鲁施氏有二子
- **分数**：戍死者固十六七（《史记》，十分之六七）
- **虚数**：千万臣而无数（《九方皋相马》，极言其多）
- **整数与零数之间加“有（又）”**：十有七年

#### 2. 量词

上古量词不发达，先秦名量词、动量词都比后代少。

- **名量**：一箪食，一瓢饮；一乘（一车四马）
- **动量**：三战三北（数词直接修饰动词）

## 代词

王力通论（十二）重点。分人称、指示、疑问三类；者、所是特殊指示代词。

### 一、人称代词

| 人称     | 常见形式                 | 注意                                                     |
| -------- | ------------------------ | -------------------------------------------------------- |
| 第一人称 | 吾、我、余、予、朕       | 吾多作主语、定语；我作宾语较自由                         |
| 第二人称 | 汝（女）、尔、若、而、乃 | “子”表敬称，您                                           |
| 第三人称 | 其、之、彼               | 其多作定语；之作宾语；上古没有真正等于现代“他”的主语代词 |

> 子之年长矣（《九方皋相马》）——子：您。

### 二、指示代词

- **近指**：此、是、斯、兹
- **远指**：彼、夫
- **无定 / 他指**：或（有的人）、莫（没有谁）

上古“是”是指示代词“这”，不是系词。判断句见下文。

> 是灭亡之道（《鲁施氏有二子》）——是：这。

### 三、疑问代词

谁、孰、何、奚、安、焉、胡、曷。疑问代词作宾语时常前置（见词序）。

> 又何马之能知也；焉往而不穷哉

### 四、者、所

- **者字结构**：V / Adj + 者 → “…的人 / 物”（施事）。好学者、唱善者。
- **所字结构**：所 + V → “被…的事物”（受事）。所务、所观。

详解见 [所字结构](/articles/gu-dai-han-yu/1-1.html)。

## 副词

修饰动词、形容词，表示程度、范围、时间、否定、语气、情态、谦敬等。胡安顺分八类，常用如下：

### 1. 程度副词

表示程度高：孔、最、甚、殊、颇、尤、至。益、愈表示程度加深，可译为“更加”。

> 谋夫孔多，是用不集。（《诗经·小雅·小旻》）——孔：很。
> 庚申，晋弑其君州蒲。称国以弑其君，君恶甚矣。（《穀梁传·成公十八年》）——甚：太、很。
> 老臣今者殊不欲食。（《战国策·赵策四》）——殊：特别。
> 绛侯得释，盎颇有力。（《史记·袁盎晁错列传》）——颇：很、相当。
> 水至清则无鱼，人至察则无徒。（东方朔《答客难》）——至：极。

表示程度轻：少、稍、略、微、差、小、颇，可译为“稍微”“略微”。少在现代汉语里是形容词，表示数量不多；这里是副词。颇也可以表示程度高，见上。

> 太后之色少解。（《战国策·赵策四》）——少：稍微。
> 于是项梁乃教籍兵法，籍大喜，略知其意，又不肯竟学。（《史记·项羽本纪》）——略：略微。
> 色厉而言方，欲有所为，微见风采，党与承其指意而显奏之。莽稽首涕泣，固推让焉。（《汉书·王莽传》）——微：略微。
> 唯班固著《百官公卿表》，记汉承秦置官本末，讫于王莽，差有条贯。（《后汉书·百官志》）——差：略微。

### 2. 范围副词

皆、尽、悉、咸、俱、唯（惟）、但、徒、独

> 臣之子皆下才也

### 3. 否定副词

- **不、弗**：一般否定。弗后面动词往往不带宾语。
- **毋、勿**：禁止，不要。
- **未**：不曾。
- **非**：否定判断（“不是”），不是一般的“不”。
- **微**：如果没有（常用于假设）。

> 色物牝牡尚弗能知；非行之谬也

### 4. 时间副词

既、已、尝、曾、将、且、方、适、曩、向

> 既反，孟氏之父子叩胸而让施氏

### 5. 语气 / 情态副词

固、必、乃、即、诚、殆、庶几

> 是乃其所以千万臣而无数者也——乃：就是。

### 6. 谦敬副词

请、谨、敬、幸、辱、伏惟（多用于对话礼貌）

### 7. 指代性副词

相、见（如“见欺”中见有指代受事的用法，与被动相关）

## 介词、连词

### 一、介词

引进对象、工具、处所、时间、原因、比较。介宾短语可在动词前，也可后置。

| 介词         | 主要作用                     | 例               |
| ------------ | ---------------------------- | ---------------- |
| 于（於）、乎 | 处所、对象、比较、被动施事   | 窘于贫；贵乎马   |
| 以           | 凭借、工具、原因；亦可表率领 | 以术干齐侯       |
| 为（wèi）    | 替、给；表原因               | 为吾之患         |
| 为（wéi）    | 被动“被”                     | 为天下笑         |
| 与           | 和、跟                       | 所与共担纆薪菜者 |

### 二、连词

连接词、短语或分句。

- **而**：承接 / 转折 / 修饰。遂刖之，而还诸鲁；子道与吾同，而功与吾异
- **以**：目的、结果，略等于“来 / 以致”。辞赏以正君
- **则**：承接、条件。疾病，则曰…
- **且、况**：递进
- **虽、若、如**：让步、假设。若用仁义治吾国
- **故、是故**：因果

“以”“与”既可作介词，也可作连词，按语法功能判定。

## 语气词、叹词、助词

### 一、语气词

#### 句末

| 语气词             | 作用               | 例             |
| ------------------ | ------------------ | -------------- |
| 也                 | 判断、肯定、解释   | 果天下之马也   |
| 矣                 | 已然、将然（动态） | 已得之矣       |
| 乎                 | 疑问、反问、感叹   | 有可以求马者乎 |
| 哉                 | 感叹、反问         | 焉往而不穷哉   |
| 与（欤）、邪（耶） | 疑问               |                |
| 耳、尔             | 而已，罢了         |                |

王力：也偏静态确认，矣偏动态变化。

#### 句首 / 句中

夫、盖、惟（维）、其（表推测、祈使）

> 夫尺蠖食黄则其身黄（《景公射出质》）——夫：发语。

### 二、叹词

嘻、噫、嗟、呜呼等，独立于句子结构之外。

> 嘻！先生何病（《原宪居鲁》）

### 三、助词

结构助词“之”最重要：

1. 定语标志：诸公子之傅
2. 取消句子独立性：羡施氏之有；弦章之廉
3. 宾语前置标志：何马之能知
4. 凑足音节（衬字）

词头、词尾（有、言、然、如等）有的语法书归入助词，词汇笔记里按构词讲。

## 兼词、固定结构与固定格式

### 一、兼词

一字兼两个词的音义。

| 兼词 | 合音              | 例                     |
| ---- | ----------------- | ---------------------- |
| 诸   | 之 + 于 / 之 + 乎 | 还诸鲁                 |
| 焉   | 于 + 之           | 有一焉                 |
| 盍   | 何 + 不           | 盍各言尔志             |
| 叵   | 不 + 可           | 居心叵测（后起义常用） |

### 二、固定结构（举例）

- **如何 / 若何 / 奈何**：怎么办
- **孰与**：与…比怎么样
- **无以 / 有以**：没有用来…的 / 有用来…的
- **所以**：用来…的方法；…的原因（≠现代“因此”）
- **以为**：认为；以（之）为

### 三、固定格式（举例）

- **不亦…乎**：不也是…吗
- **何…之有**：有什么…
- **唯…是 / 之…**：只…（宾语前置强调）
- **……之谓也**：说的就是…

## 词类活用

本是甲类词，在句中临时具备乙类词的语法功能。胡安顺、王力都列为阅读关键。

### 一、名词、形容词、数词用作动词

- **名词作动词**：遂宫而放之（施加宫刑）；杖藜而应门（拄）；// 履至尊而制六合（登）
- **形容词作动词**：正君（使君正，兼使动）；近贼
- **数词作动词**：六王毕，四海一（统一）

### 二、名词、动词作状语

名词（或动词）放在动词前修饰谓语。常见译法：

| 类型        | 译法      | 例                         |
| ----------- | --------- | -------------------------- |
| 比喻        | 像…一样   | 蚕食诸侯；云集响应         |
| 处所        | 在…       | 道听而途说                 |
| 工具 / 依据 | 用… / 按… | 箕畚运于渤海之尾；义不杀少 |
| 态度        | 把…当作   | 礼贤下士（礼：以礼）       |

### 三、使动用法

主语使宾语产生某动作或状态，客观致使。格式：使宾语怎么样。

1. **动词使动**：活之 = 使之活；饮诸大夫酒 = 使诸大夫饮
2. **形容词使动**：富其家、荣其亲、全而归之
3. **名词使动**：王我 = 使我为王；从左右，皆肘之（用肘撞）

### 四、意动用法

主语主观上认为宾语怎么样，或把宾语当作什么；客观未必如此。

1. **形容词意动**：美我 = 以我为美；耻之
2. **名词意动**：友麋鹿 = 以麋鹿为友；襟三江而带五湖

**辨析**：使动是“使宾语变”；意动是“认为 / 当作”。禄富其家是使动；吾妻之美我者是意动。

## 判断句

上古汉语判断句一般**不用系词“是”**；“是”为指示代词。判断靠语气词、副词和语序。

### 常见格式

1. **……者，……也**：廉颇者，赵之良将也。
2. **……，……也**（最常见）：臣之子皆下才也；吾弱国也。
3. **……者，……**：陈涉者，阳城人也。（也偶尔可省）
4. **……，……者也**：是乃其所以千万臣而无数者也。
5. **副词加强**：乃 / 即 / 则 / 必……也。若皋之所观，天机也。
6. **否定判断用“非”**：非行之谬也；贫也，非病也。

### 注意

- “为”可表判断（“为天下笑”的“为”是被动介词，另当别论）；“是”作判断系词是后起用法。
- 判断句主语和谓语都是名词性成分；翻译时常加“是”。

## 被动句

被动句：主语是动词的受事。分有形式标志与意念被动两类。王力归纳上古常见四种有标志句式。

### 一、有标志的被动句式

1. **于字句**：动词 + 于 + 施事
   > 窘于贫；夫赵强而燕弱，而君幸于赵王
2. **为字句**：为 + 施事 + 动词
   > 身死人手，为天下笑
3. **为……所……**
   > 若属皆且为所虏；为秦人积威之所劫
4. **见 / 见……于……**
   > 诚恐见欺于王而负赵；未见于众（《景公射出质》）

另有“被”字句，先秦少，汉代以后增多。

### 二、意念被动

无被动标志，靠语义判断主语是受事。

> 先日所用，今或弃之——所用：被采用的（道术）。过失不掩——过失不被掩盖。

## 词序

常规语序：主语—谓语—宾语。变式中最重要的是宾语前置、定语后置。

### 一、宾语前置

王力三类（胡安顺同）：

1. **否定句中代词宾语前置**

   格式：否定词 + 代词宾语 + 动词

   > 古之人不余欺也（= 不欺余）；莫我知也夫

2. **疑问代词作宾语前置**
   > 焉往（= 往焉）；沛公安在；何马之能知（兼用“之”）
3. **用“之 / 是”作标志把宾语提前**
   > 宋何罪之有；唯利是图；唯马首是瞻

谓语前置（主谓倒装）用于感叹、疑问，强调谓语：

> 败矣，子所使求马者！甚矣，汝之不惠！

### 二、定语后置

1. 中心词 + 之 + 定语 + 者：马之千里者（千里马）
2. 中心词 + 定语 + 者：求人可使报秦者
3. 数量定语后置：驾寒牛车一乘（后起义常见）

### 三、介宾短语后置

于、以、乎构成的介宾常在动词或形容词后，翻译时移到前面。

> 可告以良马 = 可以良马告之；贵乎马 = 贵于马
