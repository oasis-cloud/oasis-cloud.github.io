列出你最近一次“想做却没做”的事，尝试用“增加摩擦+绑定奖励”改写它。

具体步骤：

1. 识别触发：记录或思考本能被触发的场景
2. 改造场景: 用增加摩擦、奖励、显示目标进度的方法，让大脑走到懒模式
3. 小步实验：对目标进行拆解，持续获得多巴胺
4. 累积证据、重塑信念：新行为产生正反馈，理性策略才会真正扎根

这其实是一种系统思维，识别输入信息，触发反馈回路，通过增强回路解决问题，在转换到反馈回路，对增强回路进行抑制。

问题：晚饭后无法坚持运动

1. 饭后习惯性的坐到沙发或拿出手机，这样就会触发刷手机的行为
2. 饭后应该收拾家务、整理垃圾，将垃圾扔出去
3. 通过最小行动进行启动，先把碗收走
4. 在小目标的上面累积正反馈，直到整个链条串起来
