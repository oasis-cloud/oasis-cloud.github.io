一个东西为什么会从“我注意到了”，逐渐变成“我理解了”，最后变成“它对我有意义”。
| 阶段 | 用户心理状态 | 创作者真正要完成的任务 |
| --- | -------- | ---------------------- |
| 注意力 | “什么？” | **让用户意识到这里有东西** |
| 好奇 | “为什么？” | **制造一个用户想填补的缺口** |
| 理解 | “原来如此” | **让用户建立一个清晰的因果模型** |
| 兴趣 | “我想继续” | **让用户发现这个东西与自己持续相关** |
| 情绪 | “我有感觉” | **让信息与某种体验发生连接** |
| 记忆 | “我记住了” | **给信息建立一个容易再次唤起的结构** |
| 意义 | “这对我有价值” | **让它改变用户理解某件事情的方式** |
| 关系 | “我愿意再来” | **让用户把创作者纳入自己的持续信息环境** |

① 注意力

这里有什么东西值得用户现在处理？

② 好奇

用户脑子里缺了哪个答案？

③ 理解

我希望用户形成什么因果模型？

④ 兴趣

这个模型还能解释什么？

⑤ 情绪

用户会经历怎样的心理变化？

⑥ 记忆

这个东西挂在哪里，用户以后才能想起来？

⑦ 意义

看完以后，用户对什么事情的理解发生了变化？

⑧ 关系

为什么用户下一次还愿意回到这个世界？

传播者为什么愿意替你传播？
社交价值。
表层：
这个信息是什么？

深层：
我为什么愿意告诉你？

信息最好能够成为“社交货币”
信息要具有张力，像世界名著，会有一千个哈姆雷特。

我给你一个足够容易理解、记住、使用和重新表达的东西，然后你把它带进你的世界。

短视频创作的核心，不只是传递信息，而是通过具体内容表达一种解释、一种观点、一种态度；当这种解释能够被别人理解，并且能够让别人用来表达自己，它就开始产生传播。
