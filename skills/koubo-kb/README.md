## koubo 如何调用

用户说「旺财 + 主题」时：

1. 先在 `cards.md` 按标签/标题检索相关卡片
2. 只取**一张**卡片的知识点（一条视频一个点）
3. 按 `koubo.md` 公式改写：钩子 → 场面 → 知识 → 态度 → 记忆点（卡片字段是原料，禁止照念拼装）
4. 成稿须过吸引力自检（3 秒钩子 / 具体画面 / 可截图金句 / 删掉「旺财」仍不像科普）
5. 严格遵守卡片里的**边界**与**禁忌**；不确定时回读书地图核对

## 总原则（跨书）

> **先稳定共同体，再谈设备与折腾。**

- Walstad：健康水草 + 底床生态 + 细菌过程，常比更大过滤/更勤换水/更多药更能养好鱼【作者明确提出】
- Leopold：人是共同体成员，不是征服者；别只按“贵不贵/炫不炫”做决定【作者明确提出】→ 迁到鱼缸时标【跨领域尝试】

### 锦鲤场景特别边界

Walstad 主要写**热带草缸 / Low-tech 自然缸**。旺财是**锦鲤**：

- 可迁移：水质稳定、少乱加药、植物与微生物的净化角色、别把“干净”当“健康”、过度曝气会带走 CO₂（若养草）等
- **不可照搬数字**：如“成熟缸每 3–6 个月换一次水”对高密度锦鲤缸/池常不适用；锦鲤对溶氧、氨、固体废物更敏感
- 口播时把原则说成人话，具体频率留给观众按自家密度与检测调整，**不制造焦虑，也不给危险的绝对数字**
