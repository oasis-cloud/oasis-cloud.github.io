
## skill 定义

现在人类将 Agent 假想为“人”，人类通过约束来控制 Agent，但同时需要 Agent 能完成一些特定场景的问题处理。所以希望 Agent 像人类那样具备独特的技能，以及技能学习的能力。

为了将人类技能迁移到 Agent，我们需要明确 人类世界 是如何定义技能的。例如：削苹果皮是一种技能、鱼缸换水也是一种技能。这两个技能有一些共同的特点：
1. 可复用
2. 可迁移
3. 可量化

每个技能中包含了特定的知识和步骤，拿鱼缸换水技能来说：
1. 准备出水管和入水管
2. 水管对接
3. 打开出水阀门
4. 排放三分之一的水关闭出水阀门
5. 打开入水阀门
6. 水满停止

技能具有清晰的范式、明确的指令步骤。


## Agent 中如何将 人类技能 的概念迁移呢？

2025 年 10 月 16 日，Anthropic 官方博客正式发布 Agent Skills，专门针对 Claude 模型设计：
把整套任务流程、提示词、执行脚本、参考资料、触发规则打包成独立文件夹，支持按需加载、多技能组合、跨项目复用、版本管理，彻底区别于零散的 Function Call 与插件。

2025 年 12 月，它直接开放为跨平台通用开放标准 Agent Skills，OpenAI、Google Gemini、Cursor、GitHub Copilot 后续全部跟进兼容这套 Skill 范式。
