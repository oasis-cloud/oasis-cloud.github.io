

《驾驭智能体进化》（Harnessing Agentic Evolution）


论文核心模型是 AEvo。


### 1. 核心流程：双层循环

我们可以把这个系统看作是一个 **“带教练的训练营”**：

* **干活的 Agent (Evolution Agent)**：负责写代码（Candidate）。
* **沙箱 (Harness/Evaluator)**：**这里是关键修正！** 评估工作通常交给**自动化的工具**（如 Vitest、Playwright、Lighthouse），而不是 Meta-Agent。因为工具给出的报错信息（StackTrace）比 AI 的直觉更可靠。
* **Meta-Agent**：负责**复盘**。它拿到报错和测试分数，决定怎么修改“教案”（Prompt），从而指导下一轮干活。

### 2. 技术架构建议 (基于 LangChain)

你可以按照以下模块来封装：

#### A. 环境层 (The Harness) —— 你的“实验室”

不要让 LLM 猜代码对不对。你需要写一个 Node.js 脚本：

1. 接收 AI 生成的代码字符串。
2. 写入 `temp_component.tsx`。
3. 执行命令行：`npm run test:ui` 或 `npx playwright test`。
4. 返回结果：`{ success: false, error: "Element not found", score: 45 }`。

#### B. 干活层 (Evolution Agent) —— 你的“执行者”

用 LangChain 的 `ChatPromptTemplate` 封装。

* **输入**：任务描述 + Meta-Agent 给出的 **“当前最佳策略 (Current Best Strategy)”**。
* **输出**：纯 React/CSS 代码。

#### C. 元层 (Meta-Agent) —— 你的“大脑”

这是最核心的 LangChain Chain。

* **输入**：过去 N 轮的失败日志 + 当前 Prompt。
* **思考逻辑**：
> “前三轮尝试中，干活 Agent 都在试图用 z-index 解决遮挡，但测试反馈依然看不见按钮。这说明 z-index 策略失效了。下一轮，我要求它尝试使用 `React Portal`。”


* **输出**：更新后的 `system_instruction.md`。

### 3. 具体的伪代码逻辑 (Python/TS)

```python
# 1. 初始化
current_prompt = "帮我写一个响应式导航栏"
best_score = 0

for round in range(max_rounds):
    # 2. 干活 Agent 生成代码
    code_candidate = evolution_agent.run(instruction=current_prompt)
    
    # 3. 自动化评估 (Harness) - 这一步是客观的工具执行
    test_report = harness.evaluate(code_candidate) 
    
    if test_report.score > threshold:
        return code_candidate # 达到目标，交付用户

    # 4. Meta-Agent 介入 (复盘与进化)
    # 它阅读 test_report.error_log，然后修改 current_prompt
    current_prompt = meta_agent.revise(
        old_prompt=current_prompt,
        failure_log=test_report.log
    )
    # 存入记录，进入下一轮进化

```

### 4. 为什么 Meta-Agent 不直接负责评估？

根据论文 [Harnessing Agentic Evolution (arXiv:2605.13821)](https://arxiv.org/html/2605.13821v1) 的观点：

1. **防止“奖励作弊” (Reward Hacking)**：如果 Meta-Agent 既改代码又打分，它可能会为了省事，修改评估标准让自己“看起来”及格了。
2. **确定的反馈链**：前端开发中，浏览器控制台的 Error 是真实的物理反馈，Meta-Agent 的作用是**解读**这些 Error，而不是**创造**这些 Error。

### 💡 你可以尝试的第一个场景：

做一个 **“CSS 自动修复器”**。

* **目标**：让一个元素在所有屏幕尺寸下都水平垂直居中。
* **Harness**：用 Playwright 在 375px 和 1440px 宽度下截图，计算中心点坐标。
* **进化**：如果 AI 用了 `margin-left: 200px` 导致小屏崩了，Meta-Agent 就会在下一轮 Prompt 里写死：“禁止使用固定像素的 margin，请改用 Flexbox。”
